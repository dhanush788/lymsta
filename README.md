# lymsta.com

Static coming-soon page for **lymsta.com**, served by GitHub Pages.

- `index.html` — the page (single file, no build step)
- `404.html` — same page, so any path resolves to it
- `CNAME` — binds the Pages site to `lymsta.com`
- `og.png` — social preview card (1200×630)
- `favicon.svg`

## Editing

Edit `index.html` and push to `main`. Pages redeploys automatically.
If you change `index.html`, copy it over `404.html` too.

## Regenerating og.png

Rendered from an SVG with headless Chrome at 1200×630. Source lives in this
README's history only — recreate by screenshotting `index.html` at that size
if the brand changes.
